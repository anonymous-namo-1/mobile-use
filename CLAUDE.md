# Mobile Use

If the user asks you to set up Mobile Use (or "mobile use", "control my phone"), follow
[AGENTS.md](AGENTS.md) step by step. It starts by asking whether they want to run it on their
laptop (free, but the laptop must stay on) or on a cloud server (24/7, small monthly cost).

When Mobile Use is already set up, use the `phone` MCP tools (start with `look`) or the
`phone` command (`phone help`). Never type passwords or PINs, and ask before payments,
purchases or sending messages.
